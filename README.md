# Scene Switcher

Searchable scene switcher popup opened from the Hierarchy window, with starred scenes and quick open/ping actions.

## Installation

Add the package via the Unity Package Manager using the git URL:

```
https://github.com/WendellLeao/scene-switcher.git
```

To pin a specific version, append `#v1.0.0` (or any tag) to the URL.

## Usage

1. Click the ▾ arrow next to the scene name in the Hierarchy window.
2. Search across every scene in the project, or browse the Starred/All Scenes sections.
3. Left-click a scene to open it (Shift-click to open it additively). Right-click a scene to ping it in the Project window.
4. Click the star to add/remove a scene from Starred. The currently active scene is highlighted in the list.
